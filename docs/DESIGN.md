# Design

## Direction

Macify pairs oversized editorial type with authentic application artwork on a white canvas. It should feel playful and Mac-aware without imitating Apple or generic SaaS design.

## Visual system

- Use Caprasimo for display copy, Urbanist for interface text, and Caveat only for restrained handwritten accents.
- Use white backgrounds and project OKLCH tokens. Cobalt, orange, yellow, mint, periwinkle, amber, and aubergine provide limited emphasis.
- Show authentic app icons with a 22% corner radius and one soft shadow.
- Build hierarchy with scale, whitespace, color fields, and media—not card chrome.
- Use compact rectangular controls; reserve pills for statuses and categories.
- Avoid gradients, glass effects, nested cards, low-contrast copy, decorative motion, and Apple imitation.

## Homepage

The desktop hero uses two columns. The left presents “Mac apps worth making room for.” in three authored rows with real app icons woven into the words; the supporting sentence stays separate. The right shows one naturally proportioned preview and a compact identity label.

Directory cards use wide previews with the icon, name, and tagline beneath. Use three columns on wide screens, two on tablets, and one on phones. Keep pricing, badges, and classification off this browsing surface.

## Application page

Center “Meet”, the icon, and the application name in the hero. Follow with the official tagline and a restrained amber underline. The fact row contains pricing, up to 12 categories, and an open-source label only when applicable.

Previews keep their natural proportions. Editorial content uses one readable article column. Related applications appear as a loose icon shelf.

## Interaction and accessibility

- Search results, forms, navigation, and controls must work by keyboard.
- Navigation presents Home, Categories, and Surprise me as links, followed by a dark Submit app button linking to GitHub.
- Motion is limited to direct feedback and removed when reduced motion is requested.
- No headline or application name may clip between 320 px and desktop widths.
- Public pages share consistent responsive gutters and target WCAG 2.2 AA.
